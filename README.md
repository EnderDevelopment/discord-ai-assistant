# AI Assistant Bot

This Discord bot is designed to provide interactive and intelligent responses to user commands. It leverages the power of Discord's API to create a seamless user experience, with a focus on simplicity and ease of use. The bot is built using Python and the discord.py library, making it easy to extend and customize.

## Install

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the required dependencies using pip:
   ```
   pip install -r requirements.txt
   ```
4. Create a `.env` file in the project directory and add your Discord bot token:
   ```
   DISCORD_TOKEN=your_discord_bot_token_here
   ```

## Use

1. Invite the bot to your Discord server using the OAuth2 URL generated by the Discord Developer Portal.
2. Once the bot is in your server, you can use the following commands:
   - `!hello`: The bot will respond with "Hello!"
